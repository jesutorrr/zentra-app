# Zentra Pomodoro UX Lab

Prototipo local para comparar cinco alternativas de navegación y arranque del
temporizador Pomodoro. No comparte estado ni código con la aplicación Flutter.

## Ejecutar

Desde la raíz del repositorio:

```bash
python3 -m http.server 8844
```

Abrir:

```text
http://127.0.0.1:8844/design/pomodoro-ux-lab/
```

## Qué probar

1. Cambiar entre las cinco propuestas.
2. Alternar entre `Enfoque rápido` y `Ciclo Pomodoro`.
3. Personalizar enfoque, descansos y cantidad de sesiones.
4. Iniciar, pausar y terminar antes.
5. Cambiar entre la vista iPhone e iPad.

La configuración sólo vive durante la sesión del navegador. El objetivo es
evaluar comprensión y jerarquía, no persistencia.
